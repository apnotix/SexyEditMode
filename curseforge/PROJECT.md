# CurseForge project settings (set manually on the project page)

**Name:** SexyEditMode

**Summary (max 250 characters):**
Shared settings window and Edit Mode library for the Sexy addons (SexyLoot, SexyQuestHelper, SexyInterrupter, SexyHarvester). One window for all settings, windows movable in Edit Mode.

**Logo:** `icon.png` in the repo root (512 x 512)

**Main category:** Libraries

**Additional categories:** Miscellaneous

**Game versions:** WoW: Forever (16001) and Retail (12.1.0)

**Description:** [DESCRIPTION.md](DESCRIPTION.md)

**Dependency for the other addons:** after the first release, add SexyEditMode as `required-dependencies` in the `.pkgmeta` of SexyLoot, SexyQuestHelper, SexyInterrupter and SexyHarvester (`required-dependencies:` list `sexyeditmode` with the project's slug), and `## Dependencies: SexyEditMode` in their `.toc` files.
